# 四级90天备考 APP

面向英语基础较弱大学生的 CET-4 90 天离线备考 Android 原生应用。

## 开发基线

- Kotlin
- Jetpack Compose
- MVVM
- Room + DataStore
- Navigation Compose
- Coroutines + Flow
- Android 8.0（API 26）+
- Material Design 3 + ColorOS 轻量化视觉
- 纯本地运行，无服务端、无网络请求、无广告、无内购

## 备考周期

固定起始日期：2026-09-14

目标考试：2026 年 12 月 CET-4（具体考试日期以后以官方公布为准）

## 开发顺序

1. 项目骨架与全局主题
2. 首页每日任务
3. 备考日历
4. 学习资料
5. 题型方法库
6. 模拟考试
7. 错题与薄弱项
8. 个人中心
9. 本地持久化与状态恢复
10. 动画、深色模式、全面屏适配与最终验收

> 真实的大雁四级资料内容、章节和真题数据必须以用户提供的实际资料为准，不自行编造。
